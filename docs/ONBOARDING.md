# 🚀 TOSTIYK ERP 开发者接手与 AI 协作指南

> **当前状态**：全量测试通过（后端 55 passed, 2 skipped；前端 E2E 29 passed）。
> **用途**：供新接手的开发者，或在新的 AI 对话窗口中快速恢复上下文。

## 1. 项目背景
面向委内瑞拉市场的汽配进销存 + POS 收银系统，同时集成了 FMCG（快消品）插件。
- **技术栈**：FastAPI + SQLModel + SQLite + Alembic；Vue 3 + Vite + Tailwind；Pytest；Playwright。
- **目录规范**：根目录极简，日志在 `logs/`，字体在 `assets/STHeiti Light.ttc`；文档全在 `docs/`。

## 2. 最近完成的史诗级重构
1. **财务账龄闭环 (AR/AP)**：客户和供应商新增 `payment_terms`（账期）；销售单和采购单自动算 `due_date`；还款/付款自动按 FIFO 核销；新增账龄报表 CSV 导出。
2. **跨组件业务联动**：“智能补货”移至库存管理，勾选补货商品后一键生成采购单（自动跳转采购页并弹窗预填）。
3. **菜单与 UI 规范**：移除左侧独立“库存盘点”，合并为库存页顶部按钮；三大模块统一分页为 20条/页并带双日期过滤；清理硬编码 Emoji，统一 Lucide 图标；修复 ESC 键关闭弹窗误触退出。

## 3. 核心开发铁律（敲黑板）
- **数据一致性**：库存/欠款扣减必须用 SQL 级别的原子更新（如 `update(...).where(...)`），**绝不能用** `with_for_update()`。多步写操作（如开单扣库存）只能有**一次** `commit()`。
- **字体路径**：PDF 字体已移至 `assets/STHeiti Light.ttc`，配置文件 `app/config.py` 已指向该路径。
- **文档更新**：每次做完小功能提交 Git；每天收工或发版时，需将当天的更新总结追加到 `docs/DEVLOG.md` 或 `CHANGELOG.md`。
