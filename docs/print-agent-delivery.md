📦 Tostiyk ERP 打印代理 - 最终交付清单
==================================================
发给客户时，只需要把以下 4 个文件拷贝到 U 盘/压缩包：
1. TostiykPrintAgent.exe  (核心程序，约 40MB)
2. install.bat            (右键以管理员身份运行，安装并开机自启)
3. 一键修复打印.bat        (遇到红灯闪烁时，双击它救命)
4. uninstall.bat          (卸载时使用)

⚠️ 不需要发给客户：node_modules、package.json、agent-win.js 等源码依赖。

【安装步骤】
1. 确保打印机连接电脑并开机（Windows打印机列表中能看到）。
2. 右键点击 install.bat，选择“以管理员身份运行”。
3. 看到“安装成功”后，即可关闭窗口。以后开机自动运行，无需再管。

【常见问题排查】
1. 收银台左上角红灯闪烁：说明后台代理断开，双击“一键修复打印.bat”。
2. 杀毒软件拦截：请将 TostiykPrintAgent.exe 加入 360 / Windows Defender 白名单。
